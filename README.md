# opentube

TUI YouTube client built with bun + @opentui/solid + mpv.

## install

```sh
curl -fsSL https://raw.githubusercontent.com/gbsaito/opentube/master/install.sh | sh
```

manual alternative:

```sh
git clone https://github.com/gbsaito/opentube.git
cd opentube
bun install
ln -sf "$(pwd)/bin/opentube.ts" "$HOME/.local/bin/opentube"
```

## run

```sh
opentube
```
